# FinTrack

AI-powered expense tracker, reducing budgeting time by 87% through automated transaction categorization and analysis.

## Demo

See the live demo: [FinTrack](https://fintrack-rho.vercel.app/)

## Description
An intelligent personal finance platform that automatically categorizes transactions, predicts spending patterns, and provides personalized financial insights over time. FinTrack helps users gain control of their finances with minimal manual effort.

## Features

- AI-powered transaction categorization with high accuracy
- Secure local installation option for privacy-conscious users
- Interactive dashboard with customizable visualizations of spending patterns
- User-definable transaction categories and budget targets
